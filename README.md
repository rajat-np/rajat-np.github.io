# Rajat Soni's Personal Blog & Portfolio

[![Deploy Status](https://github.com/rajat-np/rajat-np.github.io/actions/workflows/deploy.yml/badge.svg)](https://github.com/rajat-np/rajat-np.github.io/actions/workflows/deploy.yml)

Personal blog and portfolio site built with Astro, TypeScript, and TailwindCSS. Live at [rajat-np.github.io](https://rajat-np.github.io/).

---

## 🚀 Quick Start

### Prerequisites

- **Node.js** 18.x or higher
- **npm** 9.x or higher
- **Git**

### Installation

```bash
# Clone the repository
git clone https://github.com/rajat-np/rajat-np.github.io.git
cd rajat-np.github.io

# Install dependencies
npm install

# Start development server (http://localhost:4321)
npm run dev

# Type-check and build for production
npm run build

# Preview production build locally
npm run preview
```

### Available Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server with hot reload |
| `npm run build` | Type-check TypeScript and build for production |
| `npm run preview` | Preview production build locally |
| `npm run check` | Run Astro type checking without building |
